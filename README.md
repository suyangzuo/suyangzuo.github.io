# 🚀 永恒

> 一个探索/试验性质的自学服务中心，致力于为学生提供优质的自学资源

***除非得到本项目主持人允许，禁止使用本站任何模块和原创内容参加如下项目：***
  - 教学比赛或类似比赛
  - 课题
  - 论文
  - 任何其它谋利的项目

## 🚀 快速开始

### 本地运行

1. **本地恢复`node_modules`**并启动项目

  ```
  npm -ci  #在本地生成 node_modules 目录并下载所需模块
  npm install -g nodemon  #nodemon可在代码更改后自动重启服务器
  nodemon app.js
  ```

2. **访问应用**

   打开浏览器访问 [http://localhost:3000](http://localhost:3000)
