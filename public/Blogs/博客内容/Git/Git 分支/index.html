分支简介

分支的用途

Git分支是版本控制的核心能力，它通过轻量的独立提交指针设计，从根本上解决了传统开发中的协作混乱、风险不可控等核心问题。

  • 🚀 实现高效并行开发

    多人可同时在各自分支开发不同功能，互不干扰，无需等待他人工作完成；新功能开发、紧急Bug修复、版本迭代可多条时间线同步推进，大幅提升团队开发效率。

  • ️🛡️ 实现严格风险隔离

    主分支main/master始终保留稳定可上线的代码，未完成的新功能、实验性代码完全不会污染主分支；线上出现紧急问题时，可拉出独立分支快速修复，无需中断当前正在进行的新功能开发。

  • ️👥 支撑规范团队协作

    每个人的修改都在独立分支中管理，从根源上避免多人直接修改同一处代码导致的冲突问题，天然适配代码合并、审核等协作流程，让每一次修改都可追溯、可审核。

  • ️⚡ 极低的性能开销

    分支只是一个指向提交记录的指针，仅占用几十字节存储空间，几乎零开销，切换分支的本质只是移动HEAD指针，速度极快，无需复制完整代码副本。

  • ️📌 灵活的版本回溯能力

    每个分支都保留完整独立的提交历史，出现问题时可快速定位、精准回滚，不会打乱整体开发节奏；支持基于不同分支维护多个发布版本，方便对历史版本进行补丁迭代

分支的本质

分支其实就是一个指针，指向提交记录。而当前分支称为HEAD也是一个指针，指向分支。因此，切换分支其实就是在移动HEAD指针，在不同的分支之间切换，这也是为何切换分支如此之快的根本原因。

分支操作

查看分支

      
        git branch     #查看本地分支
        git branch -r  #查看远程分支
        git branch -a  #查看所有分支

分支名称前面的*表示当前分支。

创建分支

  • 直接在本地创建

              
            #如果"分支名称"已存在，会弹出错误提示
            git branch 分支名称  #创建分支，但是不切换

    虽然在本地创建了bugfix分支，但是：

    • 当前分支依然是main
    • 远程分支并没有bugfix，因为尚未推送。

  • ️以远程分支创建本地分支

              
            git switch -c 本地分支名称 origin/远程分支名称  #创建+切换

            #或者

            git branch 本地分支名称 origin/远程分支名称  #创建
            git switch 本地分支名称  #切换

    在本地创建了一个和远程分支同步的分支feature并切换到了该分支。

切换分支

      
        git switch 分支名称
        git switch -c 分支名称  #创建分支的同时切换过去

运行命令后，当前分支变成了bugfix。

提醒

在本地创建新分支后，如果需要推送到远程仓库，则首次推送时，需要运行以下命令：

        
          #仅首次推送分支时，需要 "-u 远程仓库名称 本地分支名称" 这部分
          git push -u 远程仓库名称 本地分支名称

推送后，远程仓库也出现了bugfix分支。

删除分支

      
        git branch -d 本地分支名称  #删除已合并的分支
        git branch -D 本地分支名称  #强制删除未合并的本地分支，慎用！！！
        git push origin --delete 远程分支名称  #删除远程分支
        git fetch -p  #删除本地对远程分支的引用，最后执行

不能自己删除自己

如果当前分支是bugfix，则无法删除bugfix分支，必须先切换到别的分支。

无法删除，报错信息为：无法删除正在被工作树使用的分支。

  • 未完全合并，正常删除报错

    报错信息为：

    • 错误：分支 'bugfix' 未完全合并
    • 提示：如果你确定要删除，运行 'git branch -D bugfix'
    • 提示：运行 "git config set device.forceDeleteBranch false" 可屏蔽此提示

  • ️已完全合并，正常删除

    什么是完全合并

    完全合并 = 推送到远程分支 + 合并到本地其它分支

    注意：本地其它分支不一定是主分支，也可以是别的分支。

    经过完全合并，代表此分支所做的修改在本地和远程都已经同步。

  • ️删除远程分支

    删除后，远程仓库已经没有bugfix分支了。
