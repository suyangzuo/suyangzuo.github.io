# <center>正则表达式</center>

## 基础语法

### 元字符

|     元字符      | 含义                              | 示例    | 匹配结果示例                |
|:---------------:|-----------------------------------|---------|-----------------------------|
|       `.`       | 匹配除换行符外的任意单个字符      | a.b     | aab, a1b, a@b               |
|      `\d`       | 匹配数字 **(0-9)**                | \d{3}   | 123, 456                    |
|      `\D`       | 匹配非数字字符                    | \D{2}   | ab, @#                      |
|      `\w`       | 匹配单词字符 (字母、数字、下划线) | \w+     | hello, user_1               |
|      `\W`       | 匹配非单词字符                    | \W      | @, $, (空格)                |
|      `\s`       | 匹配空白字符 (空格、Tab、换行等)  | \s+     | , \t, \n                    |
|      `\S`       | 匹配非空白字符                    | \S{3}   | abc, 123                    |
|       `^`       | 匹配字符串开头                    | ^2026   | 必须以2026开头              |
|       `$`       | 匹配字符串结尾                    | 2026$   | 必须以2026结尾              |
|      `\b`       | 匹配单词边界                      | \bcat\b | 匹配"cat"，不匹配"location" |
|      `\B`       | 匹配非单词边界                    | \Bcat   | 匹配"location"中的"cat"     |
|     `[abc]`     | 匹配括号内的任意一个字符          | [aeiou] | a, e, i                     |
| `[a-z]` `[0-9]` | 匹配范围内的任意字符              | [a-z]   | a, b, c                     |
|    `[^abc]`     | 匹配不在括号内的任意字符          | [^0-9]  | a, B, @                     |
|     `(ab)`      | 编组匹配                          | (ab)    | abc, abab, abcd             |

### 量词

|  量词   | 含义        | 示例    | 说明                       |
| :-----: | ----------- | ------- | -------------------------- |
|   `*`   | 0 次或多次  | ab\*    | 匹配 a, ab, abb...         |
|   `+`   | 1 次或多次  | ab+     | 匹配 ab, abb... (不匹配 a) |
|   `?`   | 0 次或 1 次 | colou?r | 匹配 color 或 colour       |
|  `{n}`  | 恰好 n 次   | \d{4}   | 匹配 4 位数字，如年份      |
| `{n,}`  | 至少 n 次   | \d{3,}  | 匹配 3 位及以上数字        |
| `{n,m}` | n 到 m 次   | \d{2,4} | 匹配 2 到 4 位数字         |

## 案例分析

### 案例文本

假设有这样一段文本

```text
2026-10-09 15:30 南通崇川区探店：人均¥39的巷口咖啡馆，扫码加V：cafe_2026，试喝拿铁、美式后评分 4.9/5！
```

正则表达式的作用，就是用某种模式（规律），从文本中找出自己需要的内容。

### 提取日期

- **日期模式**  
  日期范例：2026-10-09  
  模式描述：**4**位数字`-`**2**位数字`-`**2**位数字  
  正则表达：
  - **首选** `[0-9]{4}-[0-9]{2}-[0-9]{2}`
  - **备选** `\d{2}-\d{2}-\d{4}`

### 提取价格

- **价格模式**  
  价格范例：¥39  
  模式描述：`¥`**1-3**位数字**(具体几位数字，视价格而定)**  
  正则表达：
  - **首选** `¥[0-9]{1,3}`
  - **备选** `¥\d{1,3}`
